# SQL Data Warehouse Project

A complete **SQL-based Data Warehouse implementation** demonstrating ETL pipelines, layered architecture, dimensional modeling, and analytical querying using **Microsoft SQL Server**.

This project showcases how raw data can be transformed into business-ready insights following industry-standard data engineering practices.

---

## 📌 Project Overview

The goal of this project is to design and implement a **modern data warehouse** using SQL.  
It covers the full data lifecycle:

- Ingesting raw data
- Cleaning and transforming data
- Structuring data into analytical models
- Running business-oriented analytical queries

The project follows a **Bronze–Silver–Gold architecture**, commonly used in enterprise data platforms.

---

## 🏗 Architecture

The data warehouse is organized into three logical layers:

### 🔹 Bronze Layer
- Stores raw data as ingested from source files
- Minimal transformation
- Acts as the single source of truth

### 🔹 Silver Layer
- Data cleaning and standardization
- Handling nulls, duplicates, and data type corrections
- Preparing data for analytical modeling

### 🔹 Gold Layer
- Business-ready data
- Fact and dimension tables
- Optimized for reporting and analytics

---

## ⭐ Key Features

- End-to-end **ETL pipeline** using T-SQL
- Layered warehouse architecture (Bronze / Silver / Gold)
- **Star schema** data modeling
- Reusable SQL scripts
- Data quality and validation queries
- Analytics-ready tables for BI tools
